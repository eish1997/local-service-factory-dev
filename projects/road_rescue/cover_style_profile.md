# 汽车救援门头首图风格档案

## 多模板底部服务词（第1090组起）

用户明确要求不固定同一模板或排列。首图本地后处理版本11，底部样式multi-v3；第1089组保留已展示的compact-v2/版本10，不回写历史成品。

- 8种真实版式：双排5+5、错列4+3+3、居中3+4+3、宽底3+3+4、主次2+4+4、宽顶4+4+2、左侧汽车救援标题+右侧九项、左右分栏各五项。
- 每连续8组遍历8种版式，相邻组不重复；6套配色与3种细线装饰独立轮换，一个周期144种组合。样式按组号可复现，恢复任务时不重新随机。
- 底部占高14.5%或17%，仍为单层不透明通栏、无逐项按钮、无粗描边。统一基础字号，主次版与侧栏仅有明确标题层级；10词保持完整，不增加或删除业务词。
- 模板ID、配色、版本和真实区域写入manifest/overlay plan/validation。不同组底部高度不同时，计划使用逐组区域，不用一个固定区域冒充全部模板。
- 已验证8模板×3生产高度、144组合唯一、50组均衡和相邻不重复，并实际查看8套本地渲染。此次0API，未扩组、未改照片或电话条。

## 未来首图视觉预设 v3（第1089组起）

`cover_visual_profile_v3.json` 只控制新组的镜头、建筑外观、光线、干湿状态和人物呈现。道路救援业务词、门头服务线、车辆类型与救援动作仍来自原类目配置及 `cover_scene_library.json`；共享手机纪实预设仍是 `realistic_mobile_documentary_v2`。第1088组及以前的提示词、原图与本地叠字完全保持原样。

- 新组按成套机位轮换，避免把多个建筑、天气、救援车位置和作业动作堆进一条提示词；12种建筑与机位、7种现实光线、5种人物呈现和4档清障车可见度交错使用。提示词中的结构签名只包含显著视觉轴，不把店名不同误认为构图不同。
- 目标模式已开启：未来首图额外轮换8种现实锚点，例如门口工具回收、半开工位、邻店边缘、路缘停车不齐、普通作业地面、雨棚阴影、前景局部遮挡和街边经过状态。现实锚点写入生产清单与封面签名；相邻首图不得复用同一锚点、机位和救援车可见度组合。
- 目标模式不把脏乱、雨天、黄车或橙工服当作固定滤镜。每张图仍只表现一个真实工作瞬间，优先保留自然不对称、轻微曝光差、正常使用痕迹和低频生活背景，避免居中门头加摆拍人物的模板感。
- 签名碰撞重选只变化兼容的次级元素，不改变本组机位、天气、车辆可见度、人数与号码。单开间排除双工位动作；转角招牌只用于转角建筑；人物呈现只定义服装、人数和朝向，动作沿用本组业务任务；街道时段服从光线。
- 门头的完整联系电话由模型生成在原图上方约40%范围内；本地中部电话条从第1089组起下移至高度50%–60%，保留隔离空间。号码、主标题、服务小字仍须人工看图核对，不能因为分区规则自动判合格。
- 后处理现行为10（2026-09-22底部美化），旧组仍为8；原第1089组版本9成品已归档。生产manifest、overlay plan及图片validation记录实际版本，新组电话条归一化坐标[0.025,0.50,0.975,0.60]，底部服务词为[0,0.855,1,1]。跨版本范围按组记录。
- 车辆与工服可以无字；如果有字，只能是准确的“道路救援”或“汽车救援”，其他伪字、假品牌和可读车牌均视为失败。人物要有实际工作动作，不重复安排站在黄车旁的橙衣摆拍。
- 第1089组和后续首图使用compact-v2底部：两行五项、等宽列、统一字号、无粗描边，细分隔线和少量强调色。通栏不透明底部占高14.5%，不再使用五行大黑底。6套配色×3种细线装饰共18种组合按组轮换，默认白底深灰字红色短线；全部10词及每组5张结构不变。旧1088组及以前保留120种旧样式，不回写历史图。
- 用户认可第1089组主体照片基本效果，本轮只修底部；底部新排版待用户查看，不代表车标等其他质量问题已通过，也不自动启动批量生产。

以下 v2 规则保留作历史版本说明。

历史门头模板版本：`road_rescue_storefront_mobile_v2`。该版本保留用于第1088组及以前的历史清单与回溯，不修改已生成或已锁定的批次。

参考图仅用于一次性提取以下规则。后续提示词生成和生图不再附带原始参考图，也不得把上一张生成图作为下一张参考。

- 年代感作为批量随机变量：约20%为2014–2018年经营多年但维护正常，约60%为2019–2022年适中当代感，约20%为2023–2026年较新门店。
- 门头必须是画面核心，店名、汽车救援主业务词、服务小字和已确认联系电话都作为照片内真实物理招牌的一部分由模型自然生成；道路救援本地后处理不再向门头区域添加任何文字或底板。
- 门头信息可参考真实中国汽车救援门店，从上到下形成店名、汽车救援主业务词、服务小字、联系电话四层排版；联系电话优先位于主招牌底部或右侧联系信息区，号码必须正确、清晰，并与招牌使用同一材质、透视、阴影和环境光。
- 门头上方不要另画整块彩色、半透明或发光背景板，也不要生成联系电话占位符、错误号码、额外号码、内框、外框或悬浮 UI 面板。
- 实体门头不能只是一块大底板加一行标题；至少形成主标题、业务信息和真实安装细节三个层级，并随机使用窄服务信息带、板材拼缝、金属收边、小面积强调色、普通筒灯或小型侧招。保持街边店铺真实感，不堆满文字，不使用复杂图标、虚假品牌、电话、价格或未经确认的营业承诺。
- 首图中部偏下必须预留干净横向区域，生成后由本地图像处理程序叠加“电话+已确认号码”的醒目电话条。
- 本地电话条要求居中摆放、字号很大、粗体、高对比、带描边或阴影、半透明深色底条；颜色可按批次随机，预览缩略图中也要清楚可读。
- 首图底部只允许一套本地服务项目层，文字为汽车救援、搭电救援、拖车服务、补胎换胎、送油救援、困境救援、地库救援、车辆救援、高速救援、城市路救援。样式按组可复现地轮换：8套配色、3种排版、5种简洁强调线组合为120种底部风格，深浅底色、文字配色、字号和结构持续变化，但不使用逐项UI按钮。所有底色仍完全不透明，用于屏蔽原图误生成的电话胶囊或服务方格。
- 生图提示词不得描述本地电话条或服务层的颜色、底板、按钮、宫格等具体外观；只要求中部和底部保持未排版的连续真实场景。
- 维修/救援人员工服可以出现“汽车救援”四字，黄色清障车或救援车车身可以出现“道路救援”四字；文字必须像真实服装印字或车身贴字，不要做成悬浮字幕。
- 门口出现中国式黄色清障车、真实救援装备和自然作业人员。
- 保留真实卷帘门、工具和适量生活痕迹形成的接地气氛围；建筑、车辆、警示灯、工具柜和手机画质必须服从同一年代档案，避免新旧冲突。
- 避免2000年代常见的小瓷砖主立面、密集防盗窗、重锈卷帘门、严重掉漆老卡车、红黑横条门头和土豪金立体字。
- 禁止生图模型生成悬浮字幕、彩色业务标签、额外电话水印、未确认手机号、海报排版和虚假豪华门店；唯一允许的中部大电话是生成完成后的本地后处理电话条。
- 批量变化重点：建筑、开间、招牌结构、车辆位置、镜头方向、距离、天气、营业状态和人员动作。
- 经营形态也必须随机：专门救援站、汽修+救援综合店、轮胎快修+救援店均可出现；黄色清障车可以是主角、侧面次要元素或只露出局部。
- 可加入真实维修工位、举升车辆、打开机盖作业、街道人流、电动车、邻店和行道树遮挡，让门店像正在营业而不是为拍照摆场。

## 实体门头手机实拍对齐 v2

- 忽略参考图中的任何后期覆盖文字，包括左上角区域推广字；这类文字不得进入门头关键词、排版层级或构图规则。
- 门头必须连同建筑环境一起拍到，至少可见墙面/挂板、电线/管线、邻店边缘、雨棚、卷帘门上沿、二层外墙中的两类；禁止只截取一块铺满画面的孤立招牌。
- 拍摄以街边稍低机位的轻微仰拍、左前方斜拍、右前方斜拍为主，保留自然梯形透视和轻微手机广角；完全正面视角只低频出现，且不能正交矫正、绝对水平或绝对对称。
- 门头板面应为中等高度，视觉宽高比通常约 2.0:1 至 3.4:1，足以形成四层信息；禁止生成 4:1 以上的过窄超长横条。
- 信息层级固定为：较小店名/站名、最大道路救援主业务词、四至六项服务小字、实体电话信息带。最大主词优先从“汽车救援”“道路救援”“拖车服务”中选择；店名不得压过业务主词。
- 服务小字只使用道路救援现有合法业务词，如拖车救援、搭电换胎、送油救援、故障检查、困境脱困、地库救援；不添加家电维修、管道疏通或未经确认业务。
- 优先采用普通米白/浅灰铝塑板、黑色或深灰实体字、红色或深色电话带；黄黑警示条只能作为可选的小面积下沿结构，不能每张固定复制。
- 保留板材拼缝、螺丝、金属包边、轻微雨痕灰尘、实体字厚度、自然投影和环境反光；允许经营数年的轻微褪色与安装误差，但不要破败或故意脏乱。
- 使用普通手机自动曝光和自动白平衡，允许轻微亮度不均、边缘暗部和色温偏差；禁止均匀影棚光、蓝白企业渐变、强 HDR、过度锐化和无阴影矢量质感。
- 禁止右侧楔形图标列、扳手/车辆图标矩阵、复杂品牌标志、UI 卡片、按钮、内外装饰框、悬浮底板、设计稿画布和招牌 mockup。
